# DaSelva clone-first V2: Gate A

This directory freezes a new comparison round. V1 remains preserved and runnable; V2 does not overwrite or tune it.

## Why V2 exists

V1 produced no decisive winner. C had the strongest taste and consistency because one chassis owned the page and donors stayed bounded. W demonstrated more motion ambition, but its final static design did not meet the same taste standard. The larger methodological miss was that all three outputs reinterpreted their references instead of beginning from close clones.

V2 therefore changes the experiment from inspiration-first to clone-first. Every strategy must reconstruct its selected reference geometry and motion before replacing typography, palette, imagery, identity, copy, and commercial behavior with DaSelva-owned material.

## What changes

- Business category has zero selection weight.
- Discovery queries describe visual and technical capabilities, not restaurants, food, hotels, hospitality, or sites similar to DaSelva.
- The candidate pool contains 12 to 18 sites from at least five categories; category-adjacent candidates may be no more than 25 percent of the pool.
- Fidelity is measured before the target asset swap.
- Distinctive or difficult reference decisions must be preserved, not normalized into a conventional restaurant landing page.
- W must pass a motion-free human taste review before any motion is implemented.
- The existing frozen DaSelva media pack is reused, so V2 authorizes no new image calls.

## Gate state

- Gate A: complete only when the V2 validator passes and `manifest.lock.json` matches `manifest.v2.json`.
- Gate B: authorized with the exact Gate B token and frozen in `reference-bundles.lock.json`; it performed only read-only category-blind retrieval, scoring, selection, and bounded evidence capture.
- Gate C: not authorized. Its proposed hard ceiling is 1,425 credits, with zero new media credits.
- Gates D and E: not authorized.

No V2 output directory, model call, generated clone, credit spend, commit, push, deployment, or production change was permitted in Gate B. Gate C remains a hard stop.
