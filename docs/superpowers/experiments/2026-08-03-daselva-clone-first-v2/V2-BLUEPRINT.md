# V2 blueprint

## Core method

1. Choose references from observable design capabilities with category weight set to zero.
2. Reconstruct each selected page or scene closely at desktop and mobile sizes.
3. Measure geometry, scroll length, responsive transformation, and motion against the reference.
4. Only after the baseline passes, swap DaSelva typography, palette, imagery, identity, copy, and commercial behavior.
5. Preserve unusual reference decisions unless target truth or accessibility requires an explicit divergence.

## Strategy distinction

### S: one clone

One reference owns everything. The experiment asks how far a direct clone can travel through an asset-and-content swap without losing its recognizable composition.

### C: one clone plus bounded donor transplants

One primary clone owns the complete page spine. Each donor may repair one named subsystem only after that subsystem has its own baseline clone. Donors never compete for global page ownership.

### W: cloned scenes plus a static taste stop

Every source scene is cloned independently. The target swaps are applied to a unified motion-free board. W then stops. The user reviews desktop, mobile, hero, Banda, and a transition detail without motion. Every taste dimension must score at least 4 out of 5, with an average of at least 4.2. Only an approved static design may receive a motion storyboard and implementation.

## Fidelity order

Fidelity is judged in this order:

1. section order and dominant geometry;
2. spacing, density, anchoring, overlap, and media framing;
3. mobile transformation;
4. scroll stages, pinning, trigger positions, tempo, and easing character;
5. target asset swap without semantic invention.

## Taste order

Taste is judged before motion:

1. compositional confidence;
2. typographic discipline;
3. palette and image integration;
4. cross-section coherence;
5. specificity and absence of generic AI patterns.

Motion cannot rescue a failing still frame.
