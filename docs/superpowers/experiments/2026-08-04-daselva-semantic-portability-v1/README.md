# DaSelva semantic portability test V1

**Date:** 2026-08-04

**Status:** `COMPLETE_READ_ONLY_SELECTION_TEST`

This round tests one correction to the frozen DaSelva V2 reference-selection method: a reference remains eligible as a whole, but each proposed influence must prove that its source meaning can survive the transfer.

The test reuses only the frozen Gate B bundle and DaSelva target authority. It does not perform new discovery, capture, generation, image calls, website changes, motion work, credit spending, shared writes, staging, commit, push, or deployment. Existing S, C, W0, V1, evidence, media, and previews remain untouched.

## Question

Can the current W allocation still be justified when each borrowed composition or motion subsystem must explain:

1. why it exists in the source;
2. what narrative or product meaning it communicates;
3. which equivalent target meaning is evidenced in DaSelva;
4. whether the influence remains valid after source identity, copy, media, typography, and palette are removed?

## Decision rules

- A site is never globally accepted or rejected because one subsystem is context-bound.
- `high` semantic coupling plus `none` target equivalence rejects the influence automatically.
- `high` semantic coupling plus `partial` target equivalence requires explicit human calibration before allocation.
- A low-coupling visual attribute may remain eligible even when a motion or narrative system from the same site is rejected.
- Category similarity is at most a weak contextual hint. It cannot prove semantic equivalence and does not select a reference.
- The target analogy must be supported by frozen DaSelva content. It cannot be invented after selection to rationalize an attractive effect.

## Result

The current W allocation does not pass the semantic-portability gate as a three-reference construction:

- **Bureau Rouge / Banda:** `ALLOW`. The full-bleed media plane, quiet navigation, and restrained overlay have a strong target equivalent: making the Banda the visual protagonist while the text supports the shared-table ritual.
- **Ponder / opening composition:** `ADAPT`. Dark field, spacing, contrast, and editorial restraint remain portable. The distributed-footage composition is context-bound and cannot be the opening's organizing idea without a proven DaSelva equivalent.
- **Ponder / scattered-footage-to-timeline motion:** `REJECT`. In the source it communicates raw footage becoming an editable cut. The frozen DaSelva narrative contains no equivalent timeline, editing, sorting, or organization event.
- **The Red / perspective chamber:** `HUMAN_CALIBRATION_REQUIRED`. A journey from river to table is present in DaSelva, but the specific spatial chamber is not required by that story. The analogy is partial and the subsystem has high visual dominance.

Only one of the three original W scene allocations passes unchanged. The test therefore stops before generation. The next valid selection round must either:

1. retain Bureau Rouge, use only low-coupling Ponder attributes, and discover a different semantically portable scene contribution; or
2. reduce W to two references only if both own material, justified subsystems and the target-owned scenes can carry the remaining narrative without a decorative transplant.

No new W board or motion should be produced from the original allocation.
