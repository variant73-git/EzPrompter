# Anti-AI-slop test — Layer A (craft) vs Layer B (palette)

Date: 2026-06-25. Illustrative side-by-side that validated the distilled design-quality guide
(Layer A) and the image style-extraction (Layer B). See the specs:
- `../2026-06-25-layer-A-design-quality-house-style.md`
- `../2026-06-25-layer-B-style-extraction-from-images.md`

## Method
Same brief (a productivity app landing) rendered under three conditions, screenshotted with
headless Chrome at 1200px. The HTML for each is saved alongside the PNG.

| # | File | Palette (Layer B) | Craft (Layer A) | Result |
|---|------|:---:|:---:|--------|
| 01 | `01-bare-no-palette-no-craft.png` | ❌ | ❌ | generic **purple** slop |
| 02 | `02-palette-no-craft.png` | ✅ | ❌ | **green** slop — right colors, still generic |
| 03 | `03-palette-plus-craft.png` | ✅ | ✅ | clean, intentional, on-brand |

The palette in 02/03 is the one Layer B extracted from the user's Dribbble shot, by role:
background greige, white containers, dark grayish-green secondary, lime accent, black type.

## What it proves (the two layers do separable work)
- **01 → 02** (palette alone): fixes the *colors* but does not remove the slop.
- **02 → 03** (craft alone, same palette): this is the "looks like AI vs looks designed"
  delta. Layer A's craft (asymmetric layout, weight-driven hierarchy, hairline grouping,
  contained accent, the bans) is what removes the slop.
- Conclusion: Layer B gives the right brand; Layer A gives the taste. Additive, not redundant.
  Craft carries most of the anti-slop gain and is isolable from palette.

## Caveat
These three were generated by the model directly, not through the product's run-flow pipeline,
so this is an illustrative demonstration, not a rigorous eval. A real eval injects Layer A into
the actual generation path with a neutral model and measures the delta. To be refined over the
tool's lifespan.
